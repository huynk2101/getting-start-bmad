- (decision) Vibe: warm & friendly school feel (option B). Serves both teachers (clarity/calm) and students (approachable).
- (decision) Register: playful (bold primaries/rounded/energetic), reassuring exam-taking (calm/soft/minimal distraction), softer-muted tones overall.
- (decision) Direction: Book Binder (B). Warm paper tones, muted indigo primary #6A6E9E, leather brown accent #9B7E5A. Georgia serif headers, studious trustworthy. Rounded 8px, tighter spacing, data-first labels. Calm measured voice.
- (decision) Form factor: desktop-first. Responsive down for basic usability but primary surface is laptop/desktop. Student exam-taking must work on desktop.
- (decision) IA: two separate worlds — teacher (Dashboard, Classes, Students, Exams, Results) and student (Dashboard, Schedule, Exams, Results). Top nav + sidebar. Exam-taking is a separate focused full-screen mode.
- (decision) Key screens mocked up and confirmed: Teacher Dashboard, Teacher Class Detail, Teacher Grading View, Student Dashboard, Student Exam-Taking, Student Results Detail. Book Binder direction applied across all.
- (decision) States: empty (friendly message), loading (skeleton shimmer), error (inline banner), success (toast auto-dismiss), pending (muted amber badge), absent (toggle + disabled score), finalized (full breakdown unlocked).
- (decision) Interactions: exam auto-save with checkmark per answered question, progress milestones microcopy, timer color transitions (amber at 5min, red at 1min). Grading: inline score input, tab to next student, absent toggle switch, save per-student, finalize with confirmation dialog. Exam conflict: inline warning below form, not modal. Navigation: tab switches instant, top nav standard page transition, exam launch fades to full-screen.
- (decision) Accessibility: WCAG AA contrast (indigo-on-paper 5.2:1), visible focus ring on all interactive elements, semantic HTML for tables/forms/tabs, ARIA on timer/progress/badges, full keyboard support for exam-taking, screen reader announces timer at intervals, errors via aria-live, respects prefers-reduced-motion.
- (decision) Voice and tone: calm measured professional microcopy. Teacher-facing: data-first, efficient (25 of 28 graded). Student-facing: reassuring, encouraging (You're doing great, All done Alex!). Error: friendly, actionable. Empty: warm, not clinical.
